01 / program shape

Start by declaring what the program needs.

A program can declare a locale, module, imports, prefix bindings, capability requirements, and named families before its items. These declarations establish the context for the functions, cells, and statements that follow.

locale zh;
prefix snomed: <http://snomed.info/id/>;
using Animation, LinearAlgebra;
requires [capability("host.render")];

02 / functions & effects

Make execution character visible.

Functions begin with fn and can be classified with pure, hot, cold, async, or effect. Parameters use name: Type; a return type follows ->. A budget clause may appear before the return type.

pure fn magnitude(x: f64, y: f64) -> f64 {
  return x * x + y * y;
}

effect fn main() {
  return magnitude(3.0, 4.0);
}

03 / values & expressions

Use familiar expressions, plus domain-native forms.

Vibe supports scalar literals, strings, booleans, null, records, lists, lambdas, IRIs, prefixed names, colors, quantities, and graph terms. Ordinary arithmetic, comparisons, boolean operations, member access, calls, indexing, and pipelines compose in expressions.

  • { x: 3.0, y: 4.0 } is a record.
  • [1, 2, 3] is a list.
  • #ff8800 is a color literal.
  • 2.5ms is a quantity literal.
  • 0.0 ~ 1.0 over 400ms ease linear is a tween expression.

04 / reactive declarations

State the relationship once.

A cell is introduced with cell and an expression, optionally with an effect class, parameters, or a when guard. Use a const when the value is declared once, and ordinary let bindings inside function blocks.

const MAX_OPACITY: f64 = 1.0;
cell progress := 0.5;
cell opacity when progress >= 0.0 := progress * MAX_OPACITY;

05 / host contracts

Vibe is a language; a host gives values an effect.

Source can describe presentation, bindings, hooks, fields, materials, and laws. The host owns the capability surface. Name live families only. vibe-host-0.1 is an outcome, not a freeze of ALL_BOUND. Script edits must not force a host rebuild.

bind slider <-> volume using Clamp[0.0, 1.0] resolve latest;
present lamp { color: #ff8800 pose: pose }
using LinearAlgebra;
LinearAlgebra.dot({ a: xs, b: ys })

06 / words

Human, person, handle, tool.

Say human (NaturalAgent). Law keeps person. A DID or DNS name is a handle, not a human. A chatbot is a tool. Diagnose voice is held / not yet. Ask · Keep · Talk are teachable loops — not locked top-level IA.
