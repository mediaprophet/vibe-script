who · claim · handle · tool

Room for ontology / semiotic examples. Seats are named. Living-safe: do not model a human, personhood, or living-natural relation as owl:Thing. No Host invent in this bay.

who

Human first

Example seat: a named human (NaturalAgent). Not a DID. Not a session. Marvin can drop a living-safe graph here.

Said, then leased

handle

Coord only

Example seat: did:qi:… or a DNS name as locator. Revoke the handle; the who remains. Continuity, not a mesh tick.

Never the other party

Chatbot / agent / model sits last. Useful. Not a human. Not listed as the correspondent in Talk stories.

Living-safe. Standing OWL constraints (B-OWL-PERSON / B-OWL-NATURAL / B-OWL-LIFE-UPLIFT) stay in force. Technical artifacts may use OWL where Thing is apt — humans are not those artifacts. This bay waits for Marvin examples; it does not mint ids to look finished.
