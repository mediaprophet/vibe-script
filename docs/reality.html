What it can do

Write a script. Run it. Change it without rebuilding the app.

You are the human. The law still says person. A name or login is not the person. A chatbot is a tool.

vibe-0.1 is the current dialect. The grammar may grow when humans need a better form — versioned and documented. A Host does not invent new words. The catalog already grows.
