Examples

Small programs, clear contracts.

The syntax earns its space by describing what changes, what a program needs, and what the host should present. Start here, then paste a fixture into the playground.

01 / spatial

Describe movement as a value.

Capability imports make the host contract explicit. A pure function can calculate a pose without performing effects.

using Animation;

pure fn orbit(t: f64) {
  return Animation.orbit_spin(t);
}

effect fn main() {
  return orbit(1.0);
}
Why this shape?

using Animation; declares that this source relies on the animation family. The evaluator can reject unknown family methods rather than treating a typo as an untrusted dynamic call.

02 / reactive

Let relationships do the updating.

Cells give a readable home to derived values—the relationship is evident at the point of declaration.

cell subtotal := 42;
cell tax := subtotal * 0.10;
cell total := subtotal + tax;

fn main() {
  return { total: total };
}
A useful mental model

Cells describe a graph of values. They are not a replacement for every imperative action; use functions and effect boundaries when the program must perform work.

03 / time

Treat interpolation as language-level intent.

The tween expression keeps the range, duration, and easing close together instead of scattering timing code through an application.

fn main() {
  let opacity = 0.0 ~ 1.0
    over 400ms ease cubic_out;

  return { opacity: opacity };
}
Host-facing by design

Vibe provides values and semantics. A host such as a canvas or UI runtime decides how a calculated value becomes a rendered or physical change.

04 / vocabulary

Keep domain terms canonical.

Prefixes make long IRIs legible while preserving their identity for graph, query, and provenance-oriented systems.

prefix snomed: <http://snomed.info/id/>;

pure fn term() {
  return snomed:386661006;
}
No rename layer

The program names the canonical identifier. Vocabulary support is bounded around referenced terms; it does not imply embedding an entire external ontology in the engine.

05 / UI & presentation

Zero-recompile hypermedia furniture.

Describe dock panels, sub-trays, metrics, and actions directly in VibeScript. Hot-edit north star: script changes must not force a host rebuild. This Pages workbench is not Poet furniture.

let dock_ui = {
  type: "dock_panel",
  title: "Aura Tray",
  badge: "4/4 Valid",
  collapsed: false,
  children: [
    {
      type: "subtray",
      title: "SHACL Shapes",
      children: [
        { type: "shacl_shape", shape: "soc:PeerShape", conformant: true, nodes: 42 }
      ]
    }
  ]
};
return dock_ui;
Live Hot-Reloading

VibeScript UI declarations evaluate inside the in-memory Rust/WASM AST engine. Editing source immediately updates the host interface live without rebuild cycles.

Fixture gallery

The language reaches beyond the usual demo domains.

These compact extracts mirror shipped engine fixture families: scientific computation, policy, graphics hosts, and localized authoring.

Physical quantities

pure fn delay() {
  return 500ms + 20ms;
}

Units are values with checks—not a convention left to comments.

Linear algebra

using LinearAlgebra;
return LinearAlgebra.dot({ a: xs, b: ys });

Math runs on this page. vibe-wasm 0.0.38 returns a local record — not a fake product. Do not invent extra methods.

Cosmic transforms

using Cosmic;
return Cosmic.geodetic_distance({ lat_deg: a, lon_deg: b, lat2_deg: c, lon2_deg: d });

Scientific and coordinate-system work lives on the same host surface. Args match core §11.1.

Consent workflows

requires [ capability("graph.write") ];
graph.stage(claim);
aura.validate(subject, Shape)?;
graph.commit()?;

Capability requirements and validation remain visible in the program.

Render host

using Render;
Render.gpu_set_camera({ handle, yaw, pitch, zoom });

Hosts provide capability families; source names the dependency.

Modal terms

using DeonticLogic;
return obligate { "did:q42:agent_must_sign" };

Policy expressions are terms. This Pages 0.0.38 WASM evals DeonticLogic.evaluate. Never stamps Active. A chatbot is a tool.
