The dialect

Built for systems with a sense of time and place.

VibeScript makes domain capabilities explicit, keeping authored programs readable without hiding their runtime contract.

01 / animation

Spatial motion

Compose animation catalogs and temporal interpolation directly in source for host-driven spatial experiences.

02 / cells

Reactive values

Model derived state as cells, so relationships are described once instead of reimplemented across event handlers.

03 / vocabulary

Canonical terms

Use first-class IRI prefixes for domain vocabularies while retaining canonical identifiers for graph systems.
